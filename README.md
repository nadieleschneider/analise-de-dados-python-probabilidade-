# 📊 Análise de Dados e Machine Learning com Python

Repositório dedicado aos meus estudos e projetos práticos em **Análise de Dados**, **Estatística** e **Machine Learning**, desenvolvidos durante a minha formação acadêmica em Análise e Desenvolvimento de Sistemas.

## 🚀 Tecnologias e Bibliotecas Utilizadas
* **Linguagem:** Python
* **Manipulação e Limpeza de Dados:** Pandas, NumPy
* **Visualização de Dados:** Matplotlib, Seaborn
* **Modelagem Preditiva:** Scikit-learn (Regressão Linear)
* **Ambiente de Desenvolvimento:** Google Colab / Jupyter Notebooks

## 📁 Projetos e Conteúdos do Repositório

### 1. Modelo Preditivo: Horas de Estudo vs. Notas (Regressão Linear)
* **Descrição:** Projeto prático focado na limpeza, tratamento de dados formatados e aplicação de um modelo de Regressão Linear simples para prever notas de estudantes com base nas horas dedicadas ao estudo.
* **Principais Etapas:**
  * Tratamento e normalização de dados numéricos (conversão de vírgulas para pontos em colunas decimais).
  * Análise exploratória inicial (`pandas.info()`, `df.head()`).
  * Treinamento do modelo preditivo com `train_test_split` e `LinearRegression`.
  * Avaliação de métricas de desempenho.

## 🎯 Objetivo
Demonstrar competências na extração de insights, tratamento de bases de dados reais e criação de modelos de Machine Learning aplicados à resolução de problemas.
